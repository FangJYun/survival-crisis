# Proposal

## Why

制作一款微信平台的单机 2D 俯视角生存游戏，让玩家通过白天探索采集、制造装备和建设防线，应对黑夜狂暴怪物与四季变化。以守护可迁移的营地塔作为本局目标，让战斗操作、角色成长和基地选址共同影响生存。

## What Changes

- 从空项目建立 Cocos Creator + TypeScript 游戏工程，支持微信小游戏与浏览器开发预览。
- 实现有限分块地图、白天／黄昏／黑夜、春夏秋冬，以及季节资源、温度和敌人差异。
- 提供两个不同天赋的角色，默认具备平 A、闪现、格挡，本局最多再学习并装配两种主动技能。
- 实现杀怪升级，以及伐木、采矿、采集各自的技能成长。
- 实现材料采集、怪物材料掉落、配方制造，以及白／蓝／紫／金四种稀有度装备。装备部位固定为头、衣服、鞋子、手套、武器；普通怪物可以掉落低等装备，高等装备依赖稀有材料制造。
- 实现有生命值的围墙、有限夜袭波次、怪物破墙寻路、塔防守和白天迁塔；塔被摧毁即本局结束。
- 角色死亡后可复活；五个部位的已穿戴装备分别独立抽取丢失判定，触发后永久删除，不生成可拾回遗物。未丢失装备继续保留。
- 实现版本化本地存档、切后台暂停、恢复与终局记录，以及规则测试和真机验收。
- 按“操作原型 → 第一晚闭环 → 成长 → 防守与装备 → 四季 → 发布打磨”分阶段实现；前两阶段形成首个试玩版本，不能因此省略完整范围。
- 未被用户明确指定的平衡参数以可配置初值落地，包括单件死亡丢失率 20%、约 10 分钟一天、7 天一季；这些数值不是不可调整的承诺。

## Capabilities

### New Capabilities

- `wechat-game-runtime`: 游戏工程、横屏触控、资源分包、平台适配和真机运行要求。
- `world-cycle`: 有限地图、昼夜、四季、环境生存状态与夜间狂暴。
- `hero-combat`: 两角色天赋、普通攻击、闪现、格挡和两个额外技能槽。
- `character-progression`: 击杀经验、角色升级和能力解锁。
- `resource-gathering`: 资源采集、工具条件、三类采集技能和资源刷新。
- `equipment-crafting`: 五装备槽、四稀有度、材料与低等装备掉落、配方及拆解。
- `tower-defense`: 围墙生命与维修、夜袭调度、破墙寻路、塔迁移和失败条件。
- `death-respawn`: 死亡时穿戴快照的独立永久丢失判定、复活和终局优先级。
- `local-persistence`: 本地存档、备份恢复、随机状态、暂停恢复和结算幂等。

### Modified Capabilities

无。当前没有既有规格或游戏实现。

## Impact

- 未来新增 Cocos 工程、领域规则、场景／预制体、配置表、占位与正式美术音频、规则测试和微信适配；本变更当前只产生规划文件。
- 不新增业务服务器、账号、云存档、联机、支付或广告；允许后续按发布需求托管静态资源。
- 需要 Cocos 编辑器、微信开发者工具、开发测试 AppID 和 Android／iOS 测试设备。当前已观察到 Node.js 可用，未确认 Cocos 和开发者工具的实际安装位置或可用性。
- 初版采用有限地图和受控内容量，不包含无限世界、复杂流体、全局实时生态、装备随机词条海量组合或局外永久成长。
