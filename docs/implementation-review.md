## 核对结论

- 五槽装备实例与背包拆解／换装通过同一物品规则，死亡只抽取穿戴快照，应急武器唯一且不可拆解。
- 制造与训练先完整校验，再在同一状态提交扣料交付；Session 保存失败冻结后续输入，重试保留结果。
- 迁塔开始、提交双重校验，同一塔对象保留最新生命；塔归零后不会再提交迁塔、复活或奖励。
- 普通怪只直接掉白蓝，紫金走配置配方；精英／季节材料保底与随机状态进入快照，清理不奖励。
- 多层墙采用可破坏代价路径；路径局部变化、攻击位置和轻量分离有规则回归。尚不把这些测试等同于手机 40 敌人性能通过。
- 季节与温度使用游戏时钟，复活恢复安全体温；基础白装、篝火与降温设施提供可获取应对路线。正常节奏是否充足仍需实际试玩。
- 94 项 Node 测试、TypeScript 检查、两平台实际构建代码检查通过。OpenSpec 严格校验通过。
