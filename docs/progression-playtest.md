## 新局与旧档

新游戏确认后进入角色选择：1 选林地守望者，2 选荒野猎手，也可点按钮。Esc 返回并保留原局。角色在本局内固定，复活不切换角色。

旧首夜档可以继续，默认补为 1 级守望者和零采集经验，保留世界、装备、塔、敌人和时间。旧布局不重新生成，高阶资源节点仅在新地图生成。新写入使用存档版本 2；当前程序接受版本 1 和 2，较旧程序遇到版本 2 应拒绝加载，不能回退覆盖新进度。

## 参数初值

所有参数位于 assets/resources/config/game.json 的 growth 节。

| 规则 | 初值 |
| --- | --- |
| 守望者 | 伐木耗时 ×0.8；每成功修墙 3 次，第 3 次免材料。修塔不计入，中断不累计 |
| 猎手反击 | 完美格挡后 5 秒内下一次合法普攻伤害 +50%，攻击开始消耗，整次攻击各目标不重复叠加 |
| 猎手闪现 | 成功闪现后 6 秒普攻伤害 +25%，失败闪现不触发；与反击取较大增益，不能叠乘 |
| 击杀 | 有效击杀 25 经验；清理、重复死亡通知和终局不奖励 |
| 战斗升级 | 累计阈值，保留余量；上限 20 级，每级最大生命 +5、基础攻击 +2，不免费回血给角色或塔 |
| 训练资格 | 3／6 级开放名额，最多两个；当前仅展示资格，主动技能学习将在 5.5～5.6 实现 |
| 采集 | 实际交付每份材料增加 5 经验；伐木／采矿／采集独立，上限各 10 级，每级效率 +5% |
| 高级工具 | 对应伐木／采矿 3 级后，塔旁消耗 10 木 5 石升级，工具独立于五个穿戴槽，不重复领取 |
| 高阶资源 | 硬木需升级斧，产 8 木、可再生；富矿需升级镐，产 8 石、有限产出 |

等级提高的是最大生命，当前生命不被直接填满；复活按成长后的上限恢复。成长和修墙计数保存，死亡清除临时战斗增益，保留等级、经验和工具。攻击开始时锁定本次伤害，存档保留伤害和命中集合，换装、升级或读档不改变已开始的一击。

## 人工待验步骤

1. 刷新本地页面，新建分别选择两角色，观察说明、HUD 名称与等级。退出角色选择应保留原存档。
2. 靠近同样的树采集，比较守望者与猎手进度条耗时；背包查看三条采集等级，取消操作不得涨经验。
3. 猎手面向敌人精准格挡后普攻，观察强化提示；闪现后等待增益结束，伤害应恢复。失败闪现不应显示增益。
4. 守望者损坏木墙后连续维修三次，检查第三次不扣木材；中断一次不应提前触发免费维修。
5. 打怪升级后保存退出再继续，检查角色、等级、经验、工具和修墙计数；死亡复活保持成长，新局重置。
6. 对应采集到 3 级，在背包底部升级斧／镐，再采集高级节点。升级失败和重复请求不得扣料。
