# 首夜本地试玩

当前为本地完整玩法试玩版，OpenSpec 46/55。已包含双角色、四选二技能、五槽四稀有度装备、进阶防线和四季环境，使用原创暗色手绘图集；用户体感、手机真机与完整一年端到端验收仍未完成。成长和四季说明分别见 progression-playtest.md、seasons-defense-playtest.md。

## 启动

`npm run build:web` 后运行 `npm run serve`，打开 <http://127.0.0.1:7457/>。首次点击“新的旅程”；已有进度时需要在游戏内确认替换，取消会保留原局。已结束的存档进入结算。

## 操作

| 操作 | 键盘／触控 |
| --- | --- |
| 移动 | WASD／方向键／左摇杆 |
| 普通攻击 | J／空格／平 A 按钮；站立时朝附近敌人辅助转向 |
| 闪现、格挡 | K；按住 L；或对应按钮 |

| 迁塔 | T 或迁塔按钮，再点击空地；引导 8 秒 |
| 维修、拆除 | R、X 或对应按钮；拆除不返材料，不能拆塔 |
| 背包、制造、换装 | I 或背包按钮；世界暂停，制造／拆解需靠近塔 |

后台、菜单、写盘失败等暂停原因独立保留。存档写失败会暂停世界，重试同一结果。背包中不能通过切后台继续制造。

## 第一日路线

1. 出生点旁有三棵起步树、两处石材、食物与药材；自带斧／镐。靠近后 E，站定等待进度条完成。取消、工具不符或满包不扣节点。
2. 三棵树共 12 木。塔旁用 3 木制造木剑，再点“穿戴”；剩余木材可建三段墙（每段 3 木）。木门需要 5 木。此路线只是起步示例，可探索取得更多材料。
3. 普通速度白天 360 秒、黄昏 60 秒、黑夜 180 秒；暂停菜单可开 ×4 加快本地体验。黄昏提示来袭方向，首夜来自东侧，可留入口主动迎击，或封闭后让敌人破墙。
4. 首夜预算 6 只，每 6 游戏秒尝试出现一只，夜间伤害／移速乘 1.3。击杀获得兽皮，并有 15% 概率掉落一件白／蓝装（其中蓝装占 25%）。满包保留地面掉落物。黎明夜袭撤退不奖励，野怪保留。
5. 墙 120 生命，塔 1000 生命。维修耗 1 木、引导 0.8 秒、回复至多 30；墙夜间可修，塔仅白天可修。受伤或移动会打断，未完成不扣料。
6. 迁塔仅白天、安全且在塔旁可操作，目标须为附近已探索、可达且无占位空地。成功消耗 5 木 3 石、冷却 60 秒；血量保留，原防线留地。黄昏、受伤、死亡、落点被占或读档都会中断未完成迁移。
7. 死亡后每个非空穿戴槽独立以 20% 概率永久删除；头、衣、鞋、手、武器共五槽。背包装备和材料保留，没有遗物包和拆解返还。8 秒后在塔旁合法空地复活，2 秒保护，饥饿最低恢复至 25；没有空地时等待。塔不回血，世界和夜袭继续。
8. 塔旁可以免费领取唯一一把应急木棍，不可拆解。它能被穿戴并参与死亡损失；已有一把时不能重复领取。
9. 塔归零立即终局，优先于同一 tick 的复活和迁塔。菜单保存退出后“继续游戏”会恢复同一世界、塔血量、敌人、夜袭预算及已判定损失。

倒下过一次后，背包右上角可点“上次死亡损失”回看最近一次的永久损失；刷新后仍保留。详细实际验证与可重复的独立样本见 [死亡与终局验证](outcomes-playtest-20261117.md)。

## 存档边界

- 浏览器键前缀 `survival-v1/`；微信使用 `wx.env.USER_DATA_PATH/survival-v1/`。浏览器和微信模拟器不共享存档，也不上传云端。
- 两个快照槽、四条环形事务记录，校验内容后回读确认；关键结果先冻结后提交，15 游戏秒一次周期保存，正常切后台也尝试保存。
- 加载选择最高有效序号。损坏记录会明确提示有效恢复点；高版本档阻止加载，保留原文件。
- 未成功写入的结果无法保证在进程被强制终止后保留；重新打开回到最后成功落盘点。校验和用于发现损坏，不是防作弊。
- 生成中的采集、维修和迁塔没有扣料，读档后取消。攻击命中集、敌人动作、闪现冷却、随机进度和复活倒计时保存。
