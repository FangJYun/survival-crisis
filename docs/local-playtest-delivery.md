# 暮野危机 · 本地试玩交付

2026-11-18｜Cocos Creator 3.8.8｜单机横屏｜存档版本 3

## 开始试玩

- **浏览器**：打开 <http://127.0.0.1:7457/>。预览服务关闭时，在项目根目录执行 `npm run serve`。若使用解压后的试玩包，在解压根目录执行 `node scripts/serve.mjs`，无需重新构建。
- **微信开发者工具**：导入 `build/wechatgame` 并编译，在模拟器进入游戏。2026-11-19 起使用用户 AppID，账号类型与权限需在后台确认；见[预览准备](wechat-preview-20261119.md)。未上传或发布微信。
- **游戏内手册**：主菜单或暂停菜单点击“玩法手册”（键盘 H），六页覆盖起步、守塔、战斗成长、装备损失、四季和存档。

浏览器与微信各自存档。已有进度时，“新的旅程”会先弹确认；准备保留当前局时选“继续游戏”。若只想试指定规则，用文末的隔离样本。

## 试玩路线

| 路线 | 操作与预期 |
| --- | --- |
| 首日 → 首夜 | 选角色，靠近树木按 E 或“采集”。带木材回塔旁，在背包配方里制造并穿戴木剑。按 B 或“木墙”，点击附近空地放墙。黄昏看进攻方向，夜间战斗、修墙。普通速度一天 10 分钟，暂停菜单可用 ×4 加速。 |
| 操作与成长 | 左摇杆或 WASD 移动，J 平 A、K 闪现、按住 L 格挡。试一次移动时攻击和正面格挡；比较守望者与猎手。3／6 级各开放一次塔旁技能学习，四选二。 |
| 死亡 → 补装 | 每个非空穿戴槽独立以 20% 概率永久失去该件装备。塔活着时，角色可在塔旁复活。打开背包看“上次死亡损失”，再用保留材料补装。 |
| 迁塔与保存 | 白天靠近塔，按 T 或“迁塔”，选已探索且可达的空地，站定完成引导。塔保留血量，旧墙留在原地。保存返回菜单再继续，核对装备、材料、塔的位置和血量。 |
| 长线与终局 | 每 7 天换季，夏季降温、冬季保暖；温度设施需要燃料。季末首领材料用于高稀有度装备。塔归零立即结束，从存档继续会回到结算。 |

## 隔离验证入口

- `/?qa=outcomes`：死亡损失、复活、塔毁与刷新恢复，使用独立存档空间。
- `/?qa=seasons`：四季常速关键节点，使用内存样本。
- `/?qa=defense`：闭合营地、混合墙材与横竖木门，使用内存样本，供验证相邻自动连接和放置操作。
- `/?qa=performance`：40 敌人的 60 秒浏览器负载，使用内存样本。

这些入口只在本地浏览器可用。正式试玩用首页。完整规格证据见 [验证矩阵](verification-matrix.md)。OpenSpec 仍为 **46/55**，其余九个复合任务需完成用户体验、设备或完整端到端验收后更新。回退旧版本前保留版本 3 存档和原构建；浏览器端同一端口会继续读取原档。
