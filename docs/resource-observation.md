# 资源重载观测

日期：2026-11-17。对应任务 8.3；桌面 Chrome、本机 Web 构建，非手机测试。

## 方法

打开 http://127.0.0.1:7457/?qa=resources ，点击“本地资源验证”。此入口仅允许 localhost／127.0.0.1，普通菜单不显示。程序在同一页面将五组真实 Cocos 内容包释放并重载三次，每次等待一轮节点销毁后采样。只读取存档，不新建、不提交存档。结果同时写入 RESOURCE_PROBE 控制台日志。

读取 assetManager.assets.count 与 performance.memory.usedJSHeapSize；浏览器不提供后者时明确显示不可用，不填估计值。JS 堆不含完整 GPU／原生进程内存，可能被浏览器量化，且会随 GC 波动。

截图：../.cache/qa/resources-20261117.png。三次资产数不增长，JS 堆出现回收下降；不能据此证明长期无泄漏，更不能当作手机峰值内存或 30 分钟稳定性通过。

对照：单图集同一工具入口实测资产数均为 33，JS 堆 34.91／43.78／43.06／40.70 MiB，重载耗时 427／432／384 ms。两图集增加了内存与加载成本，真机阶段需据实评估压缩、分期加载或更小纹理。
